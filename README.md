# 🖥️ YashOS

YashOS is a small web-based desktop environment I built using HTML, CSS, and JavaScript.

I wanted to make a webpage that feels more like a mini operating system instead of a normal website.

##  Live Demo

https://yashNooo.github.io/webOS/

## ✨ Features

- Desktop-style interface
- Glassmorphism top bar
- Live date and clock
- Draggable windows
- Notes application
- Create multiple notes
- Notes automatically save in localStorage so cant be deleted on reload
- Delete notes by double-clicking

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/yashNooo/webOS.git
```

Enter the project folder:

```bash
cd webOS
```

Then simply open:

```text
index.html
```

in your browser.

## 📝 Notes App

Click the **Notes** icon on the desktop to open the Notes app.

You can create and edit notes, and they are automatically stored in your browser using `localStorage`. You can delete them by double clicking on an note.

##  Why I Made This

I made YashOS to practice JavaScript DOM manipulation, browser storage, draggable UI elements, and building interactive interfaces without using a framework.
